隱私權政策

更新日期：2026-10-25

適用範圍

本政策適用於 MoonTide Backup 個人維運工具。本工具僅供擁有者管理自己的機器人備份，沒有提供公眾註冊或登入服務。

存取的資料與權限

Google Drive 授權包含檔案讀寫能力，以便尋找既有備份目錄、上傳加密備份、下載驗證及依保留規則清理舊備份。備份程式的操作對象為已設定的備份目錄，不將一般私人檔案作為備份來源。

程式會處理備份檔案、檔名與必要中繼資料，以及 Google 提供的授權與更新權杖。備份內容可能包含擁有者已授權管理的機器人資料庫、題庫素材與必要設定，均在上傳前加密。

資料用途

資料僅用於備份、完整性驗證、還原演練及必要的維運故障排查。不用於廣告、販售、個人分析或訓練 AI 模型。

保存與保護

備份使用加密方式保存於擁有者的主機及 Google Drive。解密金鑰與 OAuth 憑證存放於受存取權限保護的設定目錄，不公開於網站或程式碼儲存庫。解密驗證在受保護的暫存目錄執行。

各類備份依其設定保留，超過保留範圍時清理；Google Drive 垃圾桶仍依帳戶與平台規則處理。必要的維運紀錄用於確認工作是否成功，不刻意記錄權杖或密鑰內容。

分享與第三方服務

加密備份會傳送至擁有者使用的 Google Drive，並由其選用的主機提供維運執行環境。不出售使用者資料，也不將備份檔案設為公開分享。GitHub Pages 僅用於提供本說明頁，不承載備份或憑證。

撤銷與刪除

擁有者可在 Google 帳戶的第三方連線設定撤銷 MoonTide Backup 的存取權，停止後續雲端操作；也可停用備份排程，依需要刪除主機及 Google Drive 中的備份與垃圾桶內容。撤銷授權不會自動刪除既有備份。

Google API 資料使用

本工具對 Google API 資料的使用與轉移，遵循 Google API Services User Data Policy，包含其中的 Limited Use 要求。
